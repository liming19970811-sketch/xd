# 网页版型与 AI 训练中心 V1

## 产品边界

- 企业网页入口：`/pages/enterprise-web/pattern-center`
- 小程序只保留网页入口与说明，不注册专业管理页面。
- 版型、版本、纸样部件、尺寸、复核、训练样本、数据集、评测和模型版本继续使用现有云端集合与云函数。
- 网站不保存或展示 Provider 密钥，不执行模型自动部署。

## 工作区

1. 版型库：检索当前成员可访问的优质版型，进入详情、版本历史和派生新款。
2. 打版师复核：处理待复核队列，编辑尺寸和部件，记录修订与审核意见。
3. 训练数据：管理授权样本、训练数据集和冻结评测集。
4. 模型评测：登记模型、提示词和解析器版本，汇总外部真实结果与盲评。

## 数据与权限

- H5 使用现有 CloudBase Web SDK 调用 `pattern_review` 和 `pattern_training`。
- 小程序继续使用 `wx.cloud.callFunction`，两端共享同一云函数契约。
- 所有请求携带当前云端企业会话，企业范围和角色权限由云函数再次验证。
- 本地 mock 会话不能进入网页专业中心，也不会降级显示本地版型数据。
- 未授权版型不会进入训练或评测数据集。

## 部署与验证

1. 按现有 H5 流程构建 `unpackage/dist/build/web`。
2. 部署 `web` 目录内的内容到 `www.diebiandesign.com`。
3. 确认 CloudBase Web 安全域名与企业登录配置已就绪。
4. 运行 `node scripts/pattern-web-center-smoke.js`。
5. 使用企业云端账号验证版型库、复核队列、训练数据和评测页面。

云函数本轮未修改，无需因本轮前端接线重新部署。
