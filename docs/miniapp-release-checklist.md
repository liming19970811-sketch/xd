# 蝶变小程序 P25.7 正式构建与真机发布验收清单

## 当前状态

- 当前源码更新时间晚于 `unpackage/dist/build/mp-weixin`，现有正式产物仅可作为历史基线，不能用于本轮发布。
- 必须先在 HBuilderX 执行“发行 → 小程序-微信”，再运行本页自动命令。
- 微信开发者工具预期 AppID：`wxbfee9003d5de733e`；项目配置基础库：`3.14.3`。
- 在正式产物新鲜度、开发者工具和至少一台真机核心链路均通过前，发布结论保持“不可发布”。

## 自动检查

在项目根目录执行：

```powershell
node scripts/miniapp-release-smoke.js
node scripts/mp-package-audit.js --root unpackage/dist/build/mp-weixin --report docs/miniapp-package-report-release.md
git diff --check
```

Smoke 和包体审计都会比较正式产物与小程序源码时间。出现“正式产物晚于本轮小程序源码”失败或“产物新鲜度：已过期”时，应停止验收并重新正式构建，不得继续引用旧报告。

自动检查覆盖注册路由、tabBar、旧迁移路径、Vue 脚本与模板、作品分页和去重、对象型结果兼容、再次生成新任务、额度只读、支付隔离、乱码、敏感日志和包体警戒线。

## 微信开发者工具验收

执行前使用 release 配置重新编译 MP-WEIXIN，并清除一次本地缓存验证新用户流程。测试生成时保持当前环境既有 mock/fallback 安全配置，不开启真实 Provider 或真实额度扣减。

1. **首次新手引导**：首次进入首页显示一次；点击“立即体验”进入原生产向导；跳过后重新进入不再自动显示。
2. **首页四个主要入口**：验证主按钮以及商品上新、新品设计、营销素材入口；目标和参数与入口一致。
3. **上传真实图片**：选择、预览、重新选择均正常；未上传必需服装图片时不可提交。
4. **创建生成任务**：连续点击只创建一次；记录新 `taskId`，不改写历史任务。
5. **生成中状态**：加载文案和按钮状态明确；返回再进入后仍能恢复任务状态。
6. **成功结果**：有结果图片时显示已完成、方案、类型、时间和额度提示；空结果不得显示成功。
7. **失败重试**：模拟创建失败、轮询超时和生成失败；均显示中文原因并可重新生成。
8. **保存作品**：结果页保存后切换到作品 tab，可看到同一 `taskId` 对应作品且不重复。
9. **下载授权**：首次拒绝相册权限后出现设置引导；授权后可再次保存，不需要重启页面。
10. **分享**：分享卡片可打开对应结果；分享路径只含必要任务标识，不含 token 或签名图片地址。
11. **再次生成**：从结果页和作品详情分别触发；确认产生新 `taskId`，旧作品仍保留。
12. **作品筛选**：逐项验证全部、AI 模特图、商品主图、详情页、营销素材和视频。
13. **收藏**：收藏与取消收藏即时生效；仅改变偏好，不改变任务或作品结果。
14. **分页**：准备超过 20 条记录，上拉加载下一页；列表无重复、无跳项。
15. **我的额度**：总额度、已使用、剩余和重置时间与 `membership_usage` 一致；读取失败显示降级提示。
16. **会员套餐**：体验版、基础版、专业版、企业版展示正常；“立即升级”只提示即将开放，不拉起支付。
17. **移动审批**：无权限入口隐藏；直接进入时方法层仍拒绝；pending/disabled 成员不可操作。
18. **客户确认**：可查看项目和交付状态；确认或提出修改后状态与审批记录一致。
19. **退出并重新进入**：首页引导不重复，任务、作品偏好、套餐和额度显示保持正常。
20. **真机预览**：至少覆盖一台 iOS 和一台 Android，检查图片选择、相册授权、分享、返回栈和分包首次加载。

## 上线红线

- mock/fallback 结果不得通过正式交付审核。
- 不开启 `ENABLE_REAL_PROVIDER_CALL`、`ENABLE_REAL_QUOTA_GUARD` 或 `PROVIDER_DRY_RUN`。
- 正式小程序不得包含 enterprise-web、Cloud Alpha 或开发诊断页面。
- 云调用失败不得伪造成成功，也不得自动切换成本地写入。
- 主包小于 1MB、单分包小于 1.5MB、总包小于 8MB；非必要图片不得超过 100KB。
