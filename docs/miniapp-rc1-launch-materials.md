# 蝶变小程序 RC1 首发材料

## 版本建议

- 当前 package / manifest：`1.0.0`，versionCode `100`。
- RC1 建议内部标识：`1.0.0-rc.1`。
- 本轮不自动修改 manifest；发布负责人应在最新发布构建前统一确认版本号、构建号和体验版备注。
- 上一稳定版本：仓库内无可信记录，标记 **UNKNOWN**，需从微信公众平台版本管理核对。

## 体验版备注建议

蝶变小程序首发候选版 RC1。仅用于测试账号和非客户素材回归；AI 结果为测试结果，不可正式审核、支付或交付。重点验证上传、mock 生成、结果、生产记录、作品中心、账户服务和移动审批。

## 首发功能摘要

- 服装 AI 工具入口、上传与生产向导。
- mock 安全生成、结果查看、失败恢复与再次生成。
- 生产记录、作品中心、下载与分享。
- 我的账户、会员与额度展示、设置和企业合作入口。
- 移动企业项目概览、审批和客户确认。

不包含真实 AI Provider、真实 quota 扣点、支付、批量真实生成、自动交付或正式客户生产。

## 体验成员说明

1. 体验成员只使用测试账号和非客户图片。
2. 不输入真实客户名称、手机号、订单、报价或交付资料。
3. 看到“测试结果”、mock 或 fallback 标记时，不得用于正式审核和交付。
4. 发现任务重复、跨账号可见、额度异常或敏感信息泄露时立即停止测试并上报。
