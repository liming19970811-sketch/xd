# 隐私、数据授权与合规中心 V1

## 路由

公开协议：

- `/#/privacy`
- `/#/terms`

用户授权：

- `/#/workspace/data-consent`

后台合规：

- `/#/admin/compliance`

公开协议、用户授权和后台合规记录相互独立。

## 授权类型

系统分别管理：

- 基础服务数据处理
- 图片与文件云存储
- AI 供应商处理
- 企业团队共享
- AI训练使用
- 公开案例展示
- 营销通知

禁止使用一个总开关默认同意全部授权。

## AI 训练授权

AI 训练授权默认关闭。

开启前必须明确说明：

- 使用哪些数据
- 使用目的
- 是否包含人工修订
- 授权范围
- 保存期限
- 如何撤回

撤回授权后，未进入冻结数据集的数据立即停止使用。历史模型影响按协议和技术能力说明，不做无法兑现的承诺。

## 企业数据边界

- 企业上传素材默认仅用于完成当前服务。
- 未经授权不得跨企业复用。
- 不得自动进入公共版型库。
- 不得用于公开案例。
- 企业管理员可查看本企业授权记录。
- 企业成员个人授权不得突破企业数据政策。

## AI 供应商披露

任务提交前应提示：

- 是否调用第三方 AI 供应商
- 发送的数据类型
- 是否跨境处理
- 文件临时访问方式
- 数据保留规则

供应商变化需要更新系统记录，不能只修改隐私政策文字。

## 授权记录

每次授权保存：

- `consentId`
- 用户与企业
- 授权类型
- 协议版本
- 授权状态
- 授权时间
- 撤回时间
- 来源页面
- 适用数据范围

协议更新后保留旧版本，不覆盖历史记录。

## 用户数据权利

用户可提交：

- 查看个人数据范围
- 导出申请
- 删除申请
- 撤回可选授权
- 注销账号
- 联系隐私负责人

删除请求必须先检查项目、订单、额度、交付和法定留存要求，不能直接清空全部数据库。

## 公开案例授权

案例发布前必须确认：

- 客户授权
- 图片授权
- Logo 与品牌名称授权
- 可公开范围
- 授权有效期

授权过期或撤回后进入下线待办。

## 后台合规中心

后台展示：

- 待处理数据请求
- 授权统计
- 已撤回授权
- 待下线案例
- 协议版本
- 异常访问记录
- 数据导出记录

所有处理操作写入不可删除的审计日志。

## 验证

```powershell
npm run smoke:privacy-compliance
node --check utils/compliance/privacyConsentCenter.js
git diff --check
```

## 人工验收

1. 打开 `/#/privacy`，确认隐私政策能说明 AI 训练、供应商和用户权利。
2. 打开 `/#/terms`，确认用户协议能说明 AI 制版参考、素材权利和交付红线。
3. 打开 `/#/workspace/data-consent`，确认 AI训练、公开案例、营销通知均为独立授权。
4. 撤回 AI训练授权，确认训练候选判断拒绝。
5. 打开 `/#/admin/compliance`，确认能查看授权统计、数据请求和案例授权。
