# 自动化测试与持续回归体系 V1

## 目标

建立一套可持续运行的核心回归体系，优先保护生成、额度、审核、交付和权限链路。V1 不追求测试数量，而是先覆盖会造成重复扣费、错误交付、跨企业越权和真实生成异常的高风险点。

## 测试分层

- 单元测试：状态归一化、幂等键生成、任务参数转换、文件地址转换、版型版本创建。
- 数据层测试：额度预扣、确认、回滚、终态保护、数据范围隔离。
- 云函数/API 契约测试：请求字段、返回结构、错误码、异步任务状态、mock/真实结果标识。
- 页面组件测试：核心页面 script/template、关键 H5 smoke 页面存在性。
- H5 核心流程测试：官网入口、工作台、上传、结果页、路由刷新。
- 微信小程序人工冒烟测试：通过 HBuilderX 和微信开发者工具执行上传、生成、结果、作品、个人中心。
- 权限与安全测试：跨用户、跨企业、pending/disabled、敏感日志和 mock/fallback 交付拦截。

## 自动命令

核心回归：

```powershell
npm run test:regression:core
```

该命令会执行：

- 状态归一化检查
- 幂等键稳定性检查
- 额度预扣、确认、失败回滚和终态禁止回滚
- 权限与租户隔离
- API 返回契约
- Wanx 返回字段契约
- 上传文件源治理
- taskLayer 真实生成优先与 mock fallback 日志
- mock/fallback/空结果/未完成任务交付红线
- 批量重试只处理失败项
- 版型审核与版本保护
- H5 smoke 脚本存在性
- 敏感日志扫描

脚本会生成：

- `docs/regression-report-v1.md`

## 发布前建议命令

```powershell
npm run test:regression:core
node scripts/schema-governance-smoke.js
node scripts/smoke/provider-contract-smoke.js
git diff --check
```

如本地已经具备 H5/Playwright 环境，再执行：

```powershell
npm run test:playwright:smoke-all
```

微信小程序完整编译和人工流程仍通过 HBuilderX 与微信开发者工具完成，不用 `vue-cli-service` 替代。

## 测试数据规则

- 使用独立测试用户、企业、项目和任务 ID。
- 测试数据必须带 `test_`、`smoke_` 或 `regression_` 标记。
- 自动测试不得写入生产客户数据。
- 测试结束只清理本次创建的数据。
- 禁止无范围限制的批量删除。

## 审核红线

以下内容不得批准或交付：

- mock 结果
- fallback 结果
- 空结果
- 未完成任务
- 来源不明测试图
- 未通过审核的版型
- 已失效或无权限资产

## CI 阻断规则

- P0 失败：阻止发布，停止灰度。
- P1 失败：阻止进入正式发布流程。
- P2 失败：允许进入修复队列，但不得扩大灰度。
- P3 失败：记录并排期。

## 人工微信小程序冒烟

1. 首页打开。
2. 四大 AI 功能进入。
3. 上传图片。
4. 创建任务。
5. 结果页打开。
6. mock / fallback 结果无法审核交付。
7. 失败任务重试不重复扣费。
8. 我的作品和生产记录正常。
9. 个人中心正常。
10. 移动审批、客户确认和交付入口无 page not found。

## 发布报告

每次发布前保留报告，至少包含：

- 测试版本
- 通过与失败数量
- 失败用例
- 复现步骤
- 关联文件
- 风险等级
- 是否允许发布
