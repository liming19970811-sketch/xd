# 小程序包体治理与网站分流 V1

## 内部预算

| 项目 | 预警 | 发布阻断 |
| --- | ---: | ---: |
| 主包 | 1.2 MB | 1.5 MB |
| 单分包 | 1.2 MB | 1.5 MB |
| 总包 | 8 MB | 12 MB |
| 单资源 | 200 KB | 1 MB |

预算由 `scripts/mp-package-budget.js` 统一维护。微信限制会调整，最终结论必须以提交时微信开发者工具和官方平台检测为准。

## 小程序保留范围

- 首页、作品、我的三个 Tab。
- 生产向导、上传、生成结果和打版结构图。
- 生产记录与作品查看。
- 移动项目概览、审批、客户确认和交付状态。
- 设置、系统状态、会员与服务需求使用独立轻分包。

## 网站承接范围

- 版型库、版型详情与派生管理。
- 打版师复核队列与复核详情。
- AI 制版训练数据和模型评测。
- 样衣协作与小单生产后台。
- 企业数据、成员权限、审计、分析、报价和订单等复杂后台。

小程序入口不直接打开未配置业务域名的 `web-view`。用户主动点击后展示迁移说明，并复制 `www.diebiandesign.com` 对应工作台地址；H5 端继续进入现有工作台模块。

## 每次正式构建后

1. 使用 HBuilderX 生成正式 MP-WEIXIN 产物。
2. 执行 `npm run preflight:mp-package`。
3. 检查 `docs/miniapp-package-report.md` 和 JSON 报告。
4. 在微信开发者工具“详情/本地代码”中复核实际主包、分包和总包。
5. 任一内部阻断线、过期产物、H5 专业页面误入 MP 时停止发布准备。

只查看旧产物趋势时可运行 `npm run audit:mp-package`；它允许过期产物，但不会忽略真实超预算和编译边界错误。

## 资源规则

- 大图片、视频、PDF、字体、模型和示例数据不得随代码包内置。
- 首屏 Logo 和 Tab 图标允许保留，但仍进入单资源预警检查。
- 重复资源和可能未引用的 `static` 文件必须在报告中复核，不能仅凭脚本结果自动删除。
- 页面迁移只改变平台编译边界，不删除源码、业务 Repository 或历史数据。
