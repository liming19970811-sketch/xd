# 企业 Demo 销售演示脚本

本文档用于销售、创始人或售前同学按照固定流程演示蝶变企业版产品。演示重点是让客户理解：蝶变不是单点 AI 生图工具，而是围绕服装企业从需求、品牌资产、项目生产、交付到经营复盘的完整 AI 视觉生产系统。

## 1. 开场介绍

展示目标：

- 建立客户对蝶变企业版的整体认知。
- 说明蝶变适合服装品牌、电商团队、跨境卖家、工厂和设计工作室。
- 强调核心价值：减少重复拍摄、提升上新效率、统一品牌视觉、沉淀经营数据。

操作入口：

- 打开后台或工作台的企业 Demo 导航中心。
- 如未开启 Demo，点击「开启 Demo」。

展示字段：

| 字段 | 说明 |
| --- | --- |
| Demo 企业名称 | 当前演示客户 |
| 品牌 | 演示品牌空间 |
| 项目 | 演示企业项目 |
| 资产数量 | 已沉淀的品牌资产和作品资产 |
| 生产数量 | AI 生产任务或生产记录数量 |
| 交付状态 | 当前交付进度 |

客户价值：

- 客户可以快速看到企业版不是孤立功能，而是一套完整业务闭环。
- 演示开始前先让客户知道后续会看到哪些模块，降低理解成本。

## 2. 企业总览演示

展示目标：

- 说明企业客户从线索、项目、资产、生产到交付都有统一视图。
- 帮助客户理解 Demo 数据代表一个真实企业客户业务闭环。

操作入口：

- 后台 Demo 导航中心。
- 点击「经营驾驶舱」或停留在企业总览区域。

展示字段：

| 字段 | 说明 |
| --- | --- |
| 企业名称 | 当前企业客户 |
| 品牌名称 | 企业品牌资产归属 |
| 项目名称 | 当前演示项目 |
| 资产数量 | 品牌资产和作品资产数量 |
| 生产数量 | AI 生产记录数量 |
| 交付状态 | 项目交付状态 |

客户价值：

- 企业管理者能看到项目和资产不会散落在个人设备或聊天记录中。
- 销售可以强调“从获客到交付，业务对象可追踪”。

## 3. 品牌空间演示

展示目标：

- 展示企业可以沉淀品牌颜色、品牌模特、品牌场景和品牌模板。
- 说明品牌资产可以被后续工作台生产复用。

操作入口：

- Demo 导航中心点击「品牌空间」。
- 工作台 Demo 卡点击「品牌空间」。

展示字段：

| 字段 | 说明 |
| --- | --- |
| brandId | 品牌空间 ID |
| 品牌名称 | 企业品牌名称 |
| 品牌颜色 | 主色、辅助色等 |
| 品牌模特 | 固定模特资产 |
| 品牌场景 | 棚拍、街拍、白底等 |
| 品牌模板 | 主图、种草图、详情页模板 |

客户价值：

- 品牌视觉标准可以沉淀，不依赖每次重新描述。
- 多人协作时，团队可以复用同一套品牌资产，减少风格偏差。

## 4. 项目空间演示

展示目标：

- 展示企业项目如何承接客户需求、品牌资产和生产结果。
- 说明项目空间是企业协作和交付的主线。

操作入口：

- Demo 导航中心点击「项目空间」。
- 工作台 Demo 卡点击「项目空间」。

展示字段：

| 字段 | 说明 |
| --- | --- |
| projectId | 企业项目 ID |
| 项目名称 | 当前企业视觉项目 |
| brandId | 关联品牌 |
| customerId | 关联客户 |
| 项目状态 | 进行中、待审核、已交付等 |
| 项目资产 | 当前项目沉淀的作品和素材 |

客户价值：

- 每个企业需求都能形成项目，便于管理进度。
- 项目资产、生产记录和交付记录可以归档，减少团队沟通成本。

## 5. AI 工作台演示

展示目标：

- 展示蝶变的 AI 服装出图能力不是官网介绍，而是可操作工作区。
- 说明工作台可围绕企业项目生成商品图、种草图、跨境白底图等。

操作入口：

- Demo 导航中心点击「工作台」。
- 工作台中选择换模特、换颜色、换场景、微改款、电商主图等能力。

展示字段：

| 字段 | 说明 |
| --- | --- |
| 当前功能 type | model、color、scene、refine、ecommerce 等 |
| 上传参考图 | 用户上传或 Demo 参考图 |
| 图片比例 | 1:1、3:4、4:5 等 |
| 参数选择 | 模特、颜色、场景、风格等 |
| workspaceContext | 当前项目和品牌上下文 |

客户价值：

- 企业可以把一次生成放到明确的项目和品牌上下文中。
- 销售可以强调“不是随便生成一张图，而是围绕商业用途生成视觉资产”。

## 6. 生产记录演示

展示目标：

- 展示 AI 生产过程可以被记录和追溯。
- 说明企业可以查看生产方案、任务、结果和失败记录。

操作入口：

- Demo 导航中心点击「生产记录」。
- 工作台中点击「我的生产记录」。

展示字段：

| 字段 | 说明 |
| --- | --- |
| taskId | AI 生产任务 ID |
| planId | 生产方案 ID |
| historyId | 生产执行记录 ID |
| status | pending、processing、success、failed 等 |
| resultImageUrl | 生成结果图 |
| createdAt | 创建时间 |

客户价值：

- 企业可以追踪每次 AI 生产，不怕结果丢失。
- 管理者能复盘哪些方案更常用、哪些任务需要重试。

## 7. 资产中心演示

展示目标：

- 展示 AI 生成结果可以变成企业资产，而不是一次性图片。
- 说明资产可以关联品牌、项目、任务和交付。

操作入口：

- 项目空间中的资产面板。
- 工作台项目空间中的项目资产区域。

展示字段：

| 字段 | 说明 |
| --- | --- |
| assetId | 作品资产 ID |
| projectId | 关联项目 |
| brandId | 关联品牌 |
| taskId | 来源生产任务 |
| assetType | 资产类型 |
| imageUrl | 资产图片 |
| usage | 商品主图、种草图、批量上新图等用途 |

客户价值：

- 企业可以沉淀可复用视觉资产。
- 后续做上新、复盘、交付或二次修改时都有明确来源。

## 8. 交付中心演示

展示目标：

- 展示项目从生产结果进入审核和交付。
- 说明交付流程可以关联项目和资产。

操作入口：

- Demo 导航中心点击「交付中心」。
- 后台切换到交付视图。

展示字段：

| 字段 | 说明 |
| --- | --- |
| deliveryId | 交付记录 ID |
| projectId | 关联项目 |
| assetId | 关联资产 |
| status | 待审核、已确认、已交付等 |
| createdAt | 创建时间 |
| updatedAt | 更新时间 |

客户价值：

- 交付不再依赖零散聊天记录。
- 企业可以区分“生成结果”“审核结果”和“正式交付结果”。

## 9. 客户反馈演示

展示目标：

- 展示客户可以围绕方案或交付提出反馈。
- 说明反馈会进入项目协作流程。

操作入口：

- 后台项目详情中的客户门户预览。
- 客户门户中的反馈区域。

展示字段：

| 字段 | 说明 |
| --- | --- |
| feedbackId | 客户反馈 ID |
| projectId | 关联项目 |
| content | 客户修改意见 |
| createdAt | 反馈时间 |
| currentVersion | 当前方案版本 |
| deliveryStatus | 交付状态 |

客户价值：

- 客户反馈可以结构化沉淀，减少口头沟通遗漏。
- 企业可以围绕版本、交付和反馈持续推进项目。

## 10. 经营驾驶舱演示

展示目标：

- 展示企业管理者如何从业务数据看到经营状态。
- 串联经营驾驶舱、经营预警、经营报告、经营洞察和经营助手。

操作入口：

- Demo 导航中心点击「经营驾驶舱」。
- 后台切换经营相关 tab。

展示字段：

| 模块 | 展示字段 |
| --- | --- |
| 经营驾驶舱 | 新增客户、销售阶段金额、预计成交金额、项目数量、交付数量、API 使用情况 |
| 经营预警 | 风险类型、目标对象、风险原因、处理状态 |
| 经营报告 | 新增客户、销售变化、项目状态、交付情况、风险处理 |
| 经营洞察 | 经营总结、重点机会、风险提醒、行动建议 |
| 经营助手 | 今日建议、重点客户、重点项目、风险处理建议 |

客户价值：

- 管理者可以看到 AI 生产对销售、项目和交付的影响。
- 蝶变企业版可以从“生成工具”升级为“企业视觉生产经营系统”。

## 演示收尾话术

建议表达：

> 刚才我们演示的是从企业需求进入，到品牌资产沉淀、项目空间协作、AI 工作台生产、资产归档、交付审核，再到经营后台复盘和下一步建议的一整套闭环。对服装企业来说，核心价值不是单次生成一张图，而是把视觉生产变成可管理、可复用、可交付、可复盘的流程。

下一步建议：

- 如果客户关注成本：重点回到 AI 工作台、批量生产和经营驾驶舱。
- 如果客户关注品牌一致性：重点回到品牌空间和资产中心。
- 如果客户关注团队协作：重点回到项目空间、交付中心和客户反馈。
- 如果客户关注企业系统接入：引导到企业 API、额度管理和调用分析能力。

## 边界说明

- 本 Demo 不创建真实任务。
- 本 Demo 不调用真实 provider。
- 本 Demo 不消耗真实 quota。
- 本 Demo 不触发支付。
- 本 Demo 不修改真实客户业务数据。
- 本 Demo 只用于企业版演示和验收。
