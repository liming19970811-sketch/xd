# 蝶变小程序 RC1 体验成员测试清单

## 测试边界

- RC1 建议标识：`1.0.0-rc.1`。该标识尚未写入 manifest，测试前以体验版详情中的实际版本为准。
- 只使用测试账号、测试服装图片和非客户素材。
- Provider 必须为 mock，真实 quota、批量真实生成、自动交付和支付必须关闭。
- mock/fallback 结果必须标记为测试，不得正式审核或交付。
- 不提供微信账号、OPENID、Token、手机号、邮箱、客户素材地址或云凭证。
- 每项只填写 `PASS`、`FAIL`、`BLOCKED` 或 `NOT RUN`。未复验问题不得标记为已解决。

## 当前重点风险

- 指定的 RC1 发布说明、准入、缺陷、回归和安全报告均缺失，不能确认 P1 为 0。
- 辅助发布材料至少记录 3 个 P0：正式产物过期、产物路由不同步、真机核心链路未执行。
- 辅助权限审计记录 6 个高风险/严重集合项，线上数据库规则尚未复验。
- 批量生成入口和交付审批入口仍被 RC1 预检识别为阻塞。
- 测试优先覆盖重复提交、任务找回、作品收录、mock 交付阻断、跨账号数据和额度变化。

## 提交规则

1. 每个 FAIL 使用 [反馈模板](./rc1-feedback-template.md) 单独建文件，放入 `docs/rc1-feedback/`。
2. 截图和录屏使用反馈编号命名，不包含账号或客户信息。
3. 控制台只抄第一条相关错误和安全错误码，不复制完整请求、响应或调用栈中的敏感数据。
4. 测试完成后运行 `node scripts/rc1-feedback-summary.js`，查看 [反馈汇总](./rc1-feedback-summary.md)。
