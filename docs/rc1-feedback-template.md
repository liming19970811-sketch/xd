## 隐私与安全

禁止提交：微信账号、OPENID、UNIONID、Token、手机号、邮箱、客户素材、完整图片 URL、云凭证、完整请求或响应、完整用户和额度记录。

允许提交：页面名称、功能名称、安全错误码、耗时、状态、任务 ID 是否存在、脱敏截图和可复现步骤。

## 证据最低要求

- P0/P1：必须有稳定复现步骤和截图/录屏；能取得时附第一条相关错误。
- P2：至少有复现步骤和一项视觉或日志证据。
- P3：需说明设备宽度、字体设置或具体文案位置。
- `ready_for_retest` 不等于解决；只有在目标版本按原步骤复测通过后才可标记 `verified`。
