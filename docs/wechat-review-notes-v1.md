# 微信小程序审核说明 V1（草稿）

> 状态：**仅供负责人补全和人工复核，当前不可直接提交。** 生成日期：2026-07-28。本文不构成法律意见；微信规则、类目名称和资质要求以提交当天公众平台显示为准。

## 小程序用途

蝶变是一款服装视觉素材制作工具。用户主动选择服装图片，进入已开放的图片处理能力，创建测试任务并查看结果、生产记录和作品。企业合作入口用于提交人工设计或批量服务需求，与 AI 工具能力分开说明。

当前代码安全基线为：真实 AI Provider 默认关闭、真实额度扣减默认关闭、客户端生成失败不自动伪造成功。mock/fallback 结果仅可用于测试，不得作为正式服务、审核通过结果或正式交付。

## 推荐审核路径

1. 打开首页，确认无需管理员入口即可浏览。
2. 选择一项已完成验收的单图能力。
3. 用户主动选择统一测试服装图片；不使用客户素材或未获授权人像。
4. 选择最小必要配置并创建测试任务。
5. 查看生成状态和带“测试结果”标识的 mock 结果。
6. 进入生产记录，确认任务可找回且失败可理解。
7. 进入作品页，确认空结果、失败结果和禁止交付的 mock/fallback 不计入正式作品。
8. 进入“我的”，查看会员与额度只读状态。
9. 进入设置，查看微信隐私保护指引、系统权限管理和客服/反馈入口。
10. 用户协议和独立隐私政策页面补齐后，分别打开核验。

## 审核账号

- 当前小程序采用微信云开发身份初始化，代码中未发现传统用户名/密码登录页。
- 若审核环境能直接初始化测试身份，不应提交虚假账号密码。
- 若云端规则要求预置测试身份，由负责人在公众平台审核备注中提供专用测试账号说明；不得使用管理员账号或真实用户数据，也不得把账号写入仓库。

## 测试素材

- 使用自有或已获授权的普通服装测试图，不含客户订单、商标争议内容、公众人物或未经授权真人。
- 测试结果必须明确标记，不得进入正式交付、正式审核或客户项目。
- 不在审核说明中粘贴临时图片地址、云文件标识或内部任务类型。

## 隐私与权限用途

- 图片/相机：用户主动选择或拍摄服装、图案、面料及场景参考图，用于生成和结果展示。
- 云上传：将用户选择的素材上传至微信云开发存储，以建立任务、作品和生产记录关联。
- 保存相册：仅在用户点击下载后，把选定结果写入设备相册；不读取整个相册。
- 订阅消息：仅在用户主动点击且真实模板与云端发送能力可用时，申请任务完成/失败提醒。
- 剪贴板写入：仅在用户主动复制必要文本时调用；代码未发现读取剪贴板。
- 系统设置：只在用户主动管理权限或相册授权被拒后，经确认打开。

后台隐私保护指引必须逐项与实际 API 核对。当前源码未找到统一的 `getPrivacySetting`、`onNeedPrivacyAuthorization` 或 `requirePrivacyAuthorize` 适配，需在提交前补齐并真机验证。

## 会员、支付与企业合作

- 当前会员中心展示套餐、额度和权益，升级入口为了解/咨询，不创建支付订单。
- 仓库存在支付工具实现，但注册的小程序会员页未发现调用；审核包仍需确认构建产物不可达。
- 本版本不支持在线购买、充值、自动续费或退款，不应在审核材料中作此描述。
- 企业合作是人工设计、批量生产和企业服务需求提交，不等同于 AI 自动生成，也不等同于在线交易。
